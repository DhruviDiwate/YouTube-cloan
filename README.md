# YouTube Clone

A responsive video discovery interface inspired by YouTube, built with plain HTML, CSS, and vanilla JavaScript. Browse a curated feed, search by title or creator, filter by category, and preview videos in an embedded player.

## Features

- Responsive video grid with desktop and mobile layouts
- Search by video title, channel, or category
- Category filters and collapsible desktop navigation
- Video preview dialog with an embedded player and YouTube link
- Accessible controls, reduced-motion support, and lazy-loaded thumbnails
- Static-site setup with no build tools or runtime dependencies

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript
- YouTube thumbnail and privacy-enhanced embed URLs

## Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/DhruviDiwate/YouTube-cloan.git
   ```

2. Open the cloned project folder.

## Run locally

Open `index.html` in a browser, or start a simple local server from the project directory:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.
